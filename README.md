✨ Características Principales

- Launcher Dedicado: Interfaz gráfica diseñada para iniciar el juego fácilmente.
- Ejecutable Directo (".exe"): Acceso al juego mediante un lanzador para Windows.
- Emulación Integrada: Utiliza EmulatorJS con el núcleo de PlayStation (PSX).
- Carga Binaria: Ejecuta el juego mediante el archivo "juego.bin".
- Descarga Automática: Obtiene los componentes necesarios del emulador desde su CDN oficial.
- Soporte de Pantalla Completa: Disfruta de los duelos en pantalla completa.

---

🚀 Cómo Jugar

Es muy sencillo:

1. Descarga y descomprime el archivo ZIP del proyecto.
2. Coloca el archivo "juego.bin" dentro de la carpeta "Game".
3. Haz doble clic en "YuGiOhBinLauncher.exe" para abrir el lanzador.
4. Presiona el botón INICIAR DUELO.
5. Espera a que se carguen los componentes necesarios del emulador.
6. ¡Disfruta de Yu-Gi-Oh! Forbidden Memories! (Puedes salir rápidamente presionando la tecla F4).
