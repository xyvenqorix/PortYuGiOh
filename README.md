✨ Características Principales

- Launcher Dedicado: Interfaz gráfica para iniciar el juego fácilmente.
- Emulación Integrada: Utiliza EmulatorJS con el núcleo de PlayStation (PSX).
- Soporte Binario: Compatible con el archivo "juego.bin".
- Servidor Local: Ejecuta el emulador mediante un servidor HTTP local.
- Pantalla Completa: Disfruta del juego en una ventana adaptable y con soporte de pantalla completa.
- Descarga Automática: Obtiene los componentes necesarios del emulador desde su CDN oficial.
- Sistema de Caché: Guarda los archivos descargados para reutilizarlos posteriormente.
- Apoyo al Desarrollador: Incluye una opción para copiar la dirección de donaciones USDT (Polygon).

🚀 Cómo Jugar

Es muy sencillo:

1. Descarga y descomprime el archivo ZIP del proyecto.
2. Asegúrate de tener el archivo "juego.bin" dentro de la carpeta "Game".
3. Ejecuta el lanzador "YuGiOhBinLauncher.exe".
4. Presiona el botón INICIAR DUELO.
5. Espera a que se carguen los componentes del emulador.
6. ¡Prepárate para revivir los duelos clásicos de Yu-Gi-Oh!

Nota: Se necesita conexión a Internet durante la primera ejecución para descargar los componentes del emulador. Los archivos descargados se almacenan en la carpeta "cluster_data".

---

🎮 Controles

Los controles se gestionan desde el emulador mediante la configuración de mandos de EmulatorJS.

Puedes configurar el teclado o un control compatible desde las opciones del emulador.
